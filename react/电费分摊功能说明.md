# 电费分摊计算功能说明

## 功能概述
电费分摊计算系统用于根据供电局数据和各部门电量,自动计算各部门应分摊的电费金额。

## 后端 API

### 1. 获取供电局数据
- **接口**: `GET /api/electricity-cost/power-supply-data/get`
- **参数**: 
  - `year`: 年份
  - `month`: 月份
- **返回**: 供电局数据(如果存在)

### 2. 保存供电局数据
- **接口**: `POST /api/electricity-cost/power-supply-data/save`
- **参数**: 
  ```json
  {
    "year": 2026,
    "month": 2,
    "reading1To24": 641922,
    "amount1To24": 525408.01,
    "reading25ToEnd": 53153,
    "amount25ToEnd": 43500.6
  }
  ```

### 3. 三种计算模式
- **模式一**: `GET /api/electricity-cost/calculate-mode1?year=2026&month=2`
  - 仅使用1-24日数据计算
  
- **模式二**: `GET /api/electricity-cost/calculate-mode2?year=2026&month=2`
  - 仅使用25-月末数据计算
  
- **模式三**: `GET /api/electricity-cost/calculate-mode3?year=2026&month=2`
  - 使用全月数据计算

## 前端功能

### 1. 页面加载
- 自动加载当前年月的供电局数据
- 如果没有数据,显示空状态

### 2. 计算电费
- 选择年份、月份和计算模式
- 点击"计算电费"按钮
- 调用对应的后端 API
- 展示计算结果:
  - 供电局数据卡片
  - 部门电费明细表
  - 一级/二级部门电费分布图表

### 3. 数据展示
- **信息卡片**: 显示供电局抄表数、金额、单价等
- **数据表格**: 显示各部门的电能值和分配金额
- **图表**: 饼图展示一级和二级部门的电费分布

### 4. 导出功能
- 点击"导出Excel"按钮
- 导出当前计算结果(待实现)

## 权限说明
- 电费计算功能**不需要**车间级别的权限过滤
- 只要用户有"电费计算"页面的访问权限,就可以查看和计算所有部门的数据
- 这与月度能耗统计不同(月度能耗需要根据用户权限过滤车间数据)

## 使用流程

1. **首次使用**: 需要先在后台录入供电局数据
2. **选择时间**: 选择要计算的年份和月份
3. **选择模式**: 根据实际情况选择计算模式
4. **计算**: 点击"计算电费"按钮
5. **查看结果**: 查看表格和图表中的分摊结果
6. **导出**: 可以导出Excel报表

## 注意事项

1. 供电局数据需要提前录入
2. 如果某个时间段没有数据,对应的模式无法计算
3. 计算结果基于实际的电能表数据
4. 单价 = 供电局金额 ÷ 天石源总电量
